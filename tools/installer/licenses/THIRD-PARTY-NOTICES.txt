Bun runtime distribution review — NOT YET COMPLETE
Bun's pinned upstream LICENSE.md says it statically links JavaScriptCore/WebKit,
licensed under LGPL-2, and identifies other separately licensed linked libraries
and polyfills. The upstream instructions describe rebuilding/relinking Bun with
modified WebKit. The collected upstream file is an inventory and set of links,
not a complete copy of all embedded components' license texts or corresponding
source. Merely shipping this notice and the project MIT license is not evidence
that all binary-redistribution obligations have been met.

Before publicly distributing the compiled installer, complete the version-matched
embedded-runtime notice/source/relinking review. Until then the local installer
is a build-validation artifact, not an approved public binary release.
